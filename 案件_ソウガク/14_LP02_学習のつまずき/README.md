## パーツの割り当て（新規部分 01〜10）
自作の部品は使わず、hozon `LPパーツ集_体験談ランキング型`（https://hakobu-family.com/lp-parts/）の部品とルールで組んだ。

| 台本 | パーツ |
|---|---|
| H1・PR表記 | テキストの h1 → `mt-prbar`（LP01の行をそのままコピー） |
| FVの最後の一文 | `mt-mark`（黄＝答えの予告） |
| ページ内CTA | `mt-cta`（上の＼ひとこと／は台本03のH2「お子さんは、どこで困っていますか？」） |
| 02 読者の5つの声 | `mt-check`（下の一言＝台本の次の文「一言で「勉強が苦手」と言っても…」） |
| 03 悩み別5カード | H2直下に画像指示枠（5カードの図解）→ `mt-toc`（各カードのタイトル→G1〜G5のH2へのリンク、「→ 〜方へ」は子項目） |
| G1 ケース1〜3 | `mt-h3` |
| G3「たとえば」漢字／算数／英語 | `mt-h3` → `mt-h4`（教科名を1語だけ赤＋マーカー） |
| 読者の本音（台本のカギカッコ2行） | `mt-say`（G2・G3・G4・G5・09に1つずつ。アイコンはLP01と同じ保護者） |
| 「どこからなら始められそう？」「親が先生役を続けなくてもいい。」 | `mt-oneline` |
| G5 の注記 | `mt-small` |
| 10 H2直下 | `mt-banner`（felmatの広告主バナー。LP01の行をそのままコピー） |
| 10 の大ボタン | `mt-cta`（＼無料体験2回・1回目は保護者面談も可／） |

使っていないパーツと理由：`mt-talk`・`mt-summary`・`mt-bridge` は台本にない文言（会話・要点・受けの1行）を足す必要があるため。
G1のカギカッコ2行は `mt-say` にすると吹き出しが4行になる（ルールは2行まで）ため、本文のまま。

ルールどおりにできていない所：
- `mt-h2` は「20字前後」だが、台本のH2をそのまま使っているので長いものがある（例：10のH2は37字）
