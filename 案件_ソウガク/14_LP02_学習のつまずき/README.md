## 流れ（v4＝修正案 6e23b2c・177ac56 を反映）
悩み → 公式の体験談 → 変化 → 意味づけ → 次の疑問、をくり返し、ソウガクは「何をしてくれるか」を先に言い切る。

1. FV：「何度教えても進まないなら、同じやり方を続けなくていい。」→ PR帯 → アイキャッチ → 悩み → 答えの予告（黄）→ `mt-summary`「ソウガク公式の声にあった3つのケース」→ ボタン「ソウガクは何をしてくれる？ ↓」（`#sogaku`）
2. `mt-talk`（4つの吹き出し）→ 実例へ
3. 実例A・B・C：H2（結論型の見出し）→ 扉画像 → `mt-say → mt-story → mt-review` → `mt-oneline`
4. 実例Cの最後に `07_after_lesson_share` → `mt-voice`「3つのケースで違っていたのは「対応」」→ 「これを最初から…やっているのが、ソウガクです。」
5. `mt-bridge`「＼ソウガク／」→ H2「ソウガクは、何をしてくれるの？」→ 公式KV → `mt-spec`「まずは、ここだけ見ればOK」（中に最初のASPボタン `#cta-sogaku`）→ 中身 1〜4 → `mt-check`「こんな家庭に合いやすい」→「無料体験は「授業を試す」だけではありません」→ `mt-points` → 大ボタン
6. 反論「家でも集中できないのに、オンラインで大丈夫？」：中学2年生の実例 → テキストリンク
7. ここから下はLP01をそのまま流用

## 修正案からパーツのルールに合わせて変えたところ
| 修正案 | 実装 | ルール |
|---|---|---|
| `mt-talk` の吹き出し2つ | 4つ（「同じやり方を続けなくていいんです。」「（じゃあ、どうすれば…？）」を追加。最後の吹き出しは修正案の文を2行に） | 吹き出し4〜6個 |
| `mt-summary` の項目が「→」付きで2〜3行 | 「集中が切れても、声かけで戻れた子」など結果込みで1行に | 1項目1行 |
| `mt-oneline` が2行 | 前半を受けの文、後半を `mt-oneline` に分割（文言は同じ） | 短い1行＋前後に受けの文 |

| ソウガクのH2の直下に画像なし（公式KVを削除） | H2の直下に公式KV | H2直下は扉画像 |
| `mt-spec` の項目が「→」付きで2行・評価表とボタンなし | 項目は太字部分だけで1行、「→」の中身は下の 1〜4 で説明。評価表（体験2回・継続率・認定講師・返金）とボタン `#cta-sogaku` を中に | 1項目1行、ボタンは公式サイトへ |

| `mt-conclusion`「無料体験は…」 | `mt-h3` ＋本文（文言は同じ） | `mt-conclusion` は比較表の直下だけ |
| `mt-points` 5項目 | 4項目（「無料体験2回」と「1回目は保護者面談も可」を1つに） | 3〜4項目 |
| 最後の大ボタンが `#cta-sogaku` | `#cta-sogaku` は `mt-spec` の中へ。最後の大ボタンはひとこと「＼体験後に、お子さん用の個別指導計画／」 | ひとことは毎回変える |
| 実例Bの本文 | 「同じ「勉強が苦手」でも、止まる場所はそれぞれ違います。」を追加 | 扉画像（05）の文字を本文に |
| 実例Cに画像1枚 | `07_after_lesson_share` と、その文字を入れた2文を追加 | 文章だけの区間は1.5画面まで |
