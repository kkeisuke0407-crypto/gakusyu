# LP02 発達特性×学習のつまずき（④テール型・体験談駆動）

## 現在の正本
- `index.html`
- branch: `claude/lucid-goldberg-awfa5b`

2026-10-05の再構成で、LP02は「説明記事＋後半に体験談」ではなく、
**悩み → 公式体験談 → 変化 → 意味づけ → 次の疑問**
を繰り返してソウガクまで運ぶ構成に変更した。

## コンバージョンの流れ
1. FVで「3つの実例」と「この先にソウガクの仕組みがある」ことを予告
2. FV CTAはASPではなく `#sogaku` へジャンプ
3. `mt-talk` で読者の迷いを自分事化
4. 集中・宿題 → `mt-say → mt-story → mt-review → mt-conclusion`
5. 数の理解・計算 → `mt-say → mt-story → mt-review → mt-conclusion`
6. 親が教えるとケンカ → `mt-say → mt-story → mt-review`
7. `mt-voice` で3事例の共通点を収束
8. `mt-bridge` でソウガクを大きく登場させ、公式KV＋`mt-spec`で仕組みを説明
9. ソウガク直後に「オンラインで座っていられる？」という反論を `mt-story → mt-review` で処理
10. 無料体験 → 料金 → FAQ → 最終CTA

## 重要
- LP01のような比較・ランキングは入れない
- 競合名・競合リンクは入れない
- ソウガク登場前に、読者が「勉強法を理解して満足」して離脱しないよう、各体験談の最後に次の疑問を残す
- 300×250のASPバナーは使わない。ソウガク登場は公式KVを主役にする
- 制作用の `mt-imgslot` は全廃。公開HTMLに制作メモ・生成プロンプトを出さない
- 新規の説明画像を量産せず、既存の体験談画像・公式画像を中心に使う
- 料金・返金保証・FAQ・最終CTAなど下部の共通部分は既存LP02の完成済み共通ブロックを維持

## 使用する体験談パーツ
| パーツ | 役割 |
|---|---|
| `mt-talk` | FV直後に読者の迷いを言語化 |
| `mt-say` | 体験談の直前に「自分の悩み」として認識させる |
| `mt-story` | 公式体験談を経過として読ませる |
| `mt-review` | その事例の意味を一言で残す |
| `mt-conclusion` | 検索ニーズへの答え＋次の疑問を作る |
| `mt-voice` | 3事例を束ね、ソウガク登場の必然を作る |
| `mt-bridge` | ソウガク登場のスクロールストップ |
| `mt-spec` | 「なぜその子ごとに変えられるか」を仕組みとして提示 |
