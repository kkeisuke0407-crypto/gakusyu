## 現在の構成方針
LP02は、**検索ニーズを先に満たしてから、解決策としてサービスを提示する**。

### 前半：ソウガク名を出さない
1. FV
   - 発達特性のある子の勉強法
   - 宿題・集中・漢字・算数・親の教え方を扱う
   - 「この悩みをまとめて相談できるサービスも紹介」とだけ匂わせる
   - CTAは「この悩みを相談できるサービスを見る」→ `#service`
2. ニーズ回答
   - 宿題・着手・集中：始める／続ける／戻るのどこで止まるか
   - 漢字・算数：教科名ではなく、読む／書く／覚える／計算／文章題／手順まで分ける
   - 親の教え方：親が先生役を続けなくてもいい
   - 学校に行きづらい時期：発達特性がある子の「学習」に限定
3. ブリッジ
   - 家で毎日すべて対応するのは大変
   - 「どこで困っているかを見る／教え方を変える／発達特性を学んだ先生／家庭から相談できる」を満たすサービスがある
   - CTAで `#service` へ

### 後半：ここで初めてソウガク名を出す
4. `#service`
   - 「発達障害・グレーゾーン専門のオンライン家庭教師 ソウガク」と初めて発表
5. ソウガクは何をしてくれるか
   - 今どこで困っているかを確認 → 個別指導計画
   - 発達支援専門機関による教師研修
   - 毎回の指導報告＋教師/本部チャット
   - 無料体験2回、1回目は保護者面談も可
   - 「アセスメント」は本文の主役にしない。小注釈で公式用語として1回だけ説明
6. 公式体験談で裏付け
   - 集中が切れる → 声かけで戻る
   - 計算でつまずく → 伝え方を変える
   - 家で教えるとケンカ → 親の負担が軽くなった
7. 最大の反論
   - 「家でも集中できないのに、オンラインで大丈夫？」
   - 中学2年生の公式体験談
8. 無料体験 → 料金 → FAQ → 最終CTA

## 絶対ルール
- `#service` より前のユーザー表示文には「ソウガク」を出さない
- 前半は商品説明ではなく、検索ニーズへの回答
- 体験談はソウガク発表後に「本当にそうなのか」の裏付けとして使う
- 競合名・ランキング・比較表は入れない
- 300×250 ASPバナーは使わない
- `mt-imgslot` など制作メモを公開HTMLに残さない
- 「アセスメント」は専門用語のまま売らない
- FVと中間CTAはASP直リンクではなく `#service` へ
- 最初のASP CTAはソウガク発表後の `#cta-sogaku`
