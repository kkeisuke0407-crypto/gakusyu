発達特性のある子の勉強法。
「できない」をひとまとめにせず、つまずき方から見直す。

宿題に取りかかれない。
漢字がなかなか覚えられない。
算数だけ途中で止まってしまう。

同じ「勉強が苦手」でも、
読むところで止まる子、
書くことが大変な子、
始めるまでに時間がかかる子では、
困り方が違います。

だから、ただ
「もっと勉強させる」
のではなく、

まずは、
「どこで止まっているのか」
を整理することから。

つまずき別の考え方を見る

「勉強できない」は、ひとつの困り方ではありません

  • 「やればできるのに、なかなか始めない」
  • 「説明すると分かったように見えるのに、次の日には忘れている」
  • 「漢字だけ、何度練習しても覚えにくい」
  • 「問題文を読むところで止まる」
  • 「途中で集中が切れて、そのまま終わってしまう」

一言で「勉強が苦手」と言っても、止まっている場所は同じではありません。

  • 読むところで止まる
  • 書くところで止まる
  • 始めるまでに時間がかかる
  • 途中で集中が切れる

では、見直したいポイントが変わります。

大切なのは、「何が苦手か」だけでなく、「どこで止まっているか」を見ること。

まずは、お子さんの困り方に近いところから見てみてください。

お子さんは、どこで困っていますか？

  • 勉強法が分からない・勉強についていけない→ 勉強の進め方そのものを見直したい方へ
  • 宿題に取りかかれない・集中が続かない→ 始めるまで、続けるところで止まる方へ
  • 漢字・読み書き・算数など、一部で強くつまずく→ 教科や作業ごとに困り方が違う方へ
  • 親が教えると、ついぶつかってしまう→ 家庭だけで先生役まで抱え込んでいる方へ
  • 学校に行けない時期の勉強が心配→ 発達特性があり、家での学習を続けたい方へ

「もっとやる」より前に、どこで止まっているかを見る

発達特性のあるお子さんの勉強で悩むと、

「勉強時間を増やした方がいいのかな」
「もっと繰り返せば覚えられるのかな」

と考えてしまいがちです。

でも、始めるところで止まっているのか、
読んで理解するところで止まっているのか、
覚えたことを使うところで止まっているのかで、困り方は違います。

たとえば、

ケース1｜問題を開くまでに時間がかかる

→ 内容を理解できない以前に、「始めるところ」で止まっているかもしれません。

ケース2｜説明すると分かるのに、自分だけでは解けない

→ 「分かった」と「自分で進められる」の間に、まだ段差があるのかもしれません。

ケース3｜何度やっても同じところで止まる

→ 同じやり方を繰り返すより、まず「どこで止まっているか」を見直した方がよいこともあります。

ここで言いたいのは、原因を家庭だけで決めつけることではありません。

「できない」ではなく、どの場面で困っているのかを具体的にしていく。

それだけでも、次に何を試すかを考えやすくなります。

宿題に取りかかれないとき、「やる気がない」で終わらせない

「宿題を始めるまでに1時間かかる」
「やっと始めても、すぐ別のことをしてしまう」
「途中で止まると、そのまま戻れない」

こうした様子を見ると、つい

「早くやって」
「集中して」

と言いたくなります。

でも、家庭で見たいのは、

  • 始めるところで止まるのか。
  • 続けるところで止まるのか。
  • 最後まで終えるところで止まるのか。

という違いです。

同じ「宿題が進まない」でも、困っている場所は同じとは限りません。

だからこそ、

「なぜやらないの？」

ではなく、

「どこからなら始められそう？」

と、止まっている場所を一緒に見ていく方が、次の打ち手を考えやすくなります。

漢字・読み書き・算数。教科名だけでは見えない「つまずき」があります

  • 漢字が覚えられない
  • 漢字が書けない
  • 読み書きが苦手
  • 算数・計算で止まる
  • 図形が苦手
  • 英単語が覚えにくい

といった、かなり具体的な悩みも少なくありません。

ここでも、

「国語が苦手」
「算数が苦手」

だけで終わらせず、

読むところなのか、書くところなのか、覚えるところなのか、手順を追うところなのか。

まで見ていくことが大切です。

同じ教科でも、困り方が違えば、合う進め方も同じとは限りません。

たとえば

漢字が苦手

→ 読むのか、書くのか、覚えるのか。

算数が苦手

→ 計算なのか、文章題なのか、手順を追うことなのか。

英語が苦手

→ 単語を覚えることなのか、読むことなのか、書くことなのか。

「何の教科が苦手か」だけではなく、
どの作業で止まっているのかまで見ると、必要な学び方を考えやすくなります。

よくある質問

診断がついていなくても受けられますか？

はい。診断がなくても、グレーゾーンでも受講できます。診断名の申告や手帳・受給者証の提出も不要です。

集中が続きにくいお子さん向けに、小学生には25分、中高生には35分の短時間コースがあります。会話やゲーム要素も取り入れながら進める工夫があります。

先生が合わなかったら？

教師の交代は何度でも無料です。担当教師の性別希望も伝えられます。

授業中、親はずっとそばにいる必要がありますか？

初回はできる限り同席をお願いしていますが、その後は保護者が家にいなくても受講できます。指導内容は専用アプリで確認できます。

体験後にしつこく勧誘されませんか？

公式FAQでは、体験後の無理な勧誘は一切しないと案内されています。

1カ月全額返金保証は、本当に全額戻りますか？

対象は1カ月分の受講料で、入会金は対象外です。初回授業日から30日以内、最低1回の授業受講、保証期間内の連絡などの条件があります。対象コース・回数にも条件があるため、申込前に公式サイトで最新条件を確認してください。
