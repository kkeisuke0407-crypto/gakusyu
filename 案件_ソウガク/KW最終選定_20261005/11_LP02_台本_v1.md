# 04 G1｜勉強法・勉強できない【新規】

## H2
**「もっとやる」より前に、どこで止まっているかを見る**

発達特性のあるお子さんの勉強で悩むと、

「勉強時間を増やした方がいいのかな」

「もっと繰り返せば覚えられるのかな」

と考えてしまいがちです。

でも、始めるところで止まっているのか、  
読んで理解するところで止まっているのか、  
覚えたことを使うところで止まっているのかで、困り方は違います。

たとえば、

### ケース1
**問題を開くまでに時間がかかる**

→ 内容を理解できない以前に、「始めるところ」で止まっているかもしれません。

### ケース2
**説明すると分かるのに、自分だけでは解けない**

→ 「分かった」と「自分で進められる」の間に、まだ段差があるのかもしれません。

### ケース3
**何度やっても同じところで止まる**

→ 同じやり方を繰り返すより、まず「どこで止まっているか」を見直した方がよいこともあります。

ここで言いたいのは、原因を家庭だけで決めつけることではありません。

**「できない」ではなく、どの場面で困っているのかを具体的にしていく。**

それだけでも、次に何を試すかを考えやすくなります。

# 05 G2｜宿題・着手・集中【新規】

## H2
**宿題に取りかかれないとき、「やる気がない」で終わらせない**

「宿題を始めるまでに1時間かかる」

「やっと始めても、すぐ別のことをしてしまう」

「途中で止まると、そのまま戻れない」

こうした様子を見ると、つい

「早くやって」

「集中して」

と言いたくなります。

でも、家庭で見たいのは、

**始めるところで止まるのか。  
続けるところで止まるのか。  
最後まで終えるところで止まるのか。**

という違いです。

同じ「宿題が進まない」でも、困っている場所は同じとは限りません。

だからこそ、

「なぜやらないの？」

ではなく、

**「どこからなら始められそう？」**

と、止まっている場所を一緒に見ていく方が、次の打ち手を考えやすくなります。

# 06 G3｜読み書き・教科別のつまずき【新規】

## H2
**漢字・読み書き・算数。教科名だけでは見えない「つまずき」があります**

LP02のコアKWでは、

- 漢字が覚えられない
- 漢字が書けない
- 読み書きが苦手
- 算数・計算で止まる
- 図形が苦手
- 英単語が覚えにくい

といった、かなり具体的な悩みが多く見られました。

ここでも、

「国語が苦手」

「算数が苦手」

だけで終わらせず、

**読むところなのか、書くところなのか、覚えるところなのか、手順を追うところなのか。**

まで見ていくことが大切です。

同じ教科でも、困り方が違えば、合う進め方も同じとは限りません。

### たとえば

**漢字が苦手**
→ 読むのか、書くのか、覚えるのか。

**算数が苦手**
→ 計算なのか、文章題なのか、手順を追うことなのか。

**英語が苦手**
→ 単語を覚えることなのか、読むことなのか、書くことなのか。

「何の教科が苦手か」だけではなく、  
**どの作業で止まっているのか**まで見ると、必要な学び方を考えやすくなります。

# 13 最重要メッセージ

このLPの役割は、

**「発達特性のある子の勉強法を調べに来た人」に、いきなり家庭教師を売ることではない。**

まず、

**“勉強できない”をひとまとめにせず、どこで止まっているかを見る**

という検索ニーズへの答えを返す。

そのうえで、

**家庭だけで試行錯誤を続けるのではなく、特性を前提に、つまずき方を一緒に見てもらう選択肢がある**

とつなぎ、

ソウガクの

**アセスメント → 個別指導計画 → 指導 → 家庭との共有**

へ接続する。

王道LPの潜在訴求
**「親が先生役を続けなくていい」**
は、FVではなく、検索ニーズを満たした後の感情ブリッジとして使う。
