## ⑤ ゼロベースで再判断した結論

| 問い | 結論 | 理由 |
|---|---|---|
| 不登校専用LPは必要か | **不要** | 特性×不登校（N37）のコアは26語・月290件だけ。LP02のセクションで受ける |
| 特性のない不登校KWはターゲットか | **T2（探索）** | 公式は不登校単体を対象と明記していない（申込フォームの学習目的の選択肢のみ）。N09・N28・N29は探索で、LP根拠に入れない |
| 療育・放デイをLP02に入れるか | **入れない** | ソウガクは療育・福祉サービスではない。N30はT3（REVIEW）。LP02のVolにも含めていない |
| 一般受験KWを採用する意味はあるか | **ない** | 「中学受験」「高校受験」単体は対象者と判断できず、目的が受験情報。N33はEXCLUDE。特性×受験（N27a）はT1だが、最初の答えが受験・進路のため探索・保留（LPの根拠にしない） |
| 一般の塾・家庭教師KWはコアか | **探索** | 発達特性の文脈がない（N10〜N13はT2）。王道LPで低CPC探索のみ |
| N36（隣接ブランド指名）は採用すべきか | **採用しない（EXCLUDE）** | 大半が公式サイト・ログイン目的。N35（隣接ブランド×評判・料金）は探索に残す |
| LP05を作る根拠は残るか | **残らない** | 特性語を含む家庭学習の悩みはN24・N22aでLP02に入る。「中学生 勉強しない」等はT2 |
| 新LP第一候補はN24か | **はい**（N24単独475語・月31,960件。LP02コア519語・月32,580件の98%） | 対象者確度が高く（T1）、コアVolが最大（月31,960件）、王道LPと最初の答えが違う（比較ではなく「どう対応するか」） |

**発達特性×受験・進学（N27a・127語・月9,740件）**：対象者はT1。ただし最初に知りたいのは受験・進路で、LP02とも王道LPとも答えが違う。LP設計コアから外して低CPC探索として配信し、Search Terms・MCVで受験・進路の反応を見てから独立LPの要否を再判断する。

## ⑥ v1からの主な変更

- LP03（不登校）・LP04（合わない）・LP05（家庭学習の共通テール）を取り下げ。v1のLP数5本 → v2は2本
- N27a（特性×受験・進学）はT1のまま、LP02のコアから外して探索・保留に（2026-10-05 ユーザー指示）
- 療育（N30）・一般の勉強法（N31）・一般教材（N32）を採用→REVIEW、一般受験（N33）・習い事（N34）・隣接ブランド指名（N36）を採用→EXCLUDE
- 不登校・一般の塾家庭教師・競合（特性語なし）・一般家庭の悩み・隣接ブランド×評判を、採用→低CPC探索（LP根拠外）
- 特性語＋「英語」だけのKW（発達障害 英語 等）は英訳を調べている可能性が高いためREVIEW。adhd トライアスロンはEXCLUDE

## ⑦ 未知数・注意

- HSC・ギフテッド・緘黙・起立性調節障害が公式対象に含まれるかは未確認（T2）。ソウガクに確認できればT1へ上げられる
- 知的障害・境界知能は、公式の対象表記（発達障害・グレーゾーン）に明記はないが、利用者の声に知的障がいの例があるためT1とした
- ③競合（特性語なし）は探索・王道LPへの送客を維持（競合専用LP・競合名FVのLPは作らない）
- マッチタイプは決定事項（10円前後の完全一致）を維持。A3第7章との差はSTEP8で確認
- 配信KWの確定はSTEP11 A1-30。本表は一次評価
