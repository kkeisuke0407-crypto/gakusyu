# ソウガク 出稿候補KW 機械仕分け（2026-10-05）

## 方針（決定）
- 母集団68,428KWは保存。調査母集団と広告投入KW数は一致させない。
- 広告投入前に落とすのは **「明確な不適合」と「意味的重複」だけ**。
- 判定基準は1つ：**「この検索をしている人にソウガクを提示して、無料体験を申し込む合理的なストーリーを1本でも作れるか？」**
  - YES → 残す（KEEP / CORE）
  - NO → 除外（EXCLUDE）
  - 機械で決めきれない → REVIEW
- 検索vol（「100以上だけ」等）・KWP単価・「情報収集っぽい」では落とさない。テールを拾うのが今回の強み。
- KEEPは **10円前後の完全一致** で市場に聞く。COREは別管理で、必要ならCPCを上げて取りにいく。
- 人が見るのは **EXCLUDE と REVIEW だけ**。KEEPとCOREは基本そのまま投入。

## 判定の定義
- **EXCLUDE（絶対にないもの）**：求人・講師・社員・研修など働く側／既存利用者の手続き（ログイン・振替・時間割等）／事業者・経営・投資／教員の業務書式（指導案・所見）／研究・論文・語義／成人当事者の生活・仕事・恋愛／0〜3歳／大学受験・資格試験・試験事務（特性・支援文脈なし）／競合短縮名の別業種誤爆（リバランス=投資、gips=石膏、あすなろ=介護等）／子ども・学習・特性・支援のどれにも接続しない語
- **CORE（本命）**：特性/不登校×家庭教師・塾・個別・学習支援／特性/不登校×比較・おすすめ／③A直接競合／③X終了競合（メガスタ）／③Bカテゴリ競合×口コミ・評判・料金・比較・体験・退会・合わない・特性
- **KEEP（低CPC探索）**：上記以外で成約ストーリーを否定できないもの（勉強しない・宿題・集中・教え方・特性理解・不登校・受験・療育・競合周辺・一般の塾/家庭教師探し 等）
- **REVIEW**：未登録の固有名詞×料金/口コミ、「トライ＋地名」、講師/先生語のみ、大学生×家庭教師、資格語、服薬 等

## 意味的重複の落とし方
Google広告の完全一致は「同じ意味・同じ意図」の検索にも出るため、同義の表記揺れは代表1語だけ投入する。
- 分かち書き・語順・助詞の差（例：発達障害 家庭教師／家庭教師 発達障害／発達障害の家庭教師）
- 表記揺れ（発達障がい/発達障害、子ども/子供、LD/学習障害、ADHD/注意欠如多動症、月謝/料金/値段、ランキング/人気/おすすめ、中1/中学1年 等）
- 「子供」は残りが2語以上の具体KWのときだけ吸収（「英語」と「子ども 英語」は別扱い）
- 「専門・対応・向け」は家庭教師・塾等のサービス語があるときだけ吸収
- 「とは」は意図が変わるので吸収しない
- 代表は CORE > KEEP > REVIEW、同順位なら検索vol最大 → KWP由来 → 短い表記

## LP（A/B/C/D）
- **A サービス直結**：発達特性×オンライン家庭教師／比較・料金（現行の台本LPがベース）
- **B 比較・乗り換え**：普通の塾・家庭教師が合わない子に（競合・一般塾/家庭教師・地域塾）
- **C 家庭学習・特性の悩み**：親だけで抱え込まなくていい（勉強しない・宿題・集中・教え方・特性理解・療育・教材）
- **D 不登校・学校・進路**：学びの遅れと居場所（不登校・支援級/通級・転入編入・受験）

## 確信度
- EXCLUDE/REVIEW：ルールごとに 高/中/低
- KEEP：特性・不登校・サービス語・競合を含む=高、保護者の悩み語・乗換え語を含む=中、それ以外=低
