# ソウガク 王道LP v3 実装指示

## 目的
既存のソウガクLPを、`王道LP_最終稿_v3` の構成に合わせて実装する。
新しい訴求や文章を勝手に追加せず、既存の体験談ランキング型パーツ（`parts.css` の mt-*）を最大限再利用する。

## 対象
- ベース: `案件_ソウガク/13_LP_台本版/`
- 主要ファイル: `index.html`, `parts.css`, `style.css`
- 実装先は同フォルダでよいが、作業前にバックアップ用コピーを作ってもよい
- 既存の運営者情報 / privacy / disclosure / CTA_URL 共通化は維持する
- noindex / nofollow は維持する

## 絶対ルール
1. 文言は `王道LP_最終稿_v3` を正本とする。勝手な言い換え・要約・追加は禁止。
2. AIっぽい抽象共感（「寄り添います」「大丈夫です」「一人じゃありません」等）を追加しない。
3. 親を責める表現、子どもを「やる気がない」で断定する表現は禁止。
4. 比較表では ◎○△× を使わない。4社の公式事実を並列表示する。
5. ランキングだけを「当サイト独自評価」として明示する。
6. 体験談はソウガク公式掲載内容の要約のみ。創作・脚色は禁止。
7. 料金・無料体験・診断なしOK等の条件は、台本記載の範囲だけ使う。
8. 母子父子家庭の割引率は公式ページ間に記載差があるため、具体率を出さない。
9. 「本人が嫌でも受講できる」とは書かない。1回目を保護者面談にできる事実だけ使う。
10. スマホ375pxで横スクロールや崩れが出ないようにする。

## 感情ブリッジ
毎日そばで見ているからこそ、
「何が合っていないんだろう」と分からなくなることがあります。

家庭教師を探しても、「マンツーマン」「個別対応」という言葉はどこも似ています。
だからこそ、名前や知名度より、“何を見て、どう支えてくれるか”で比べてみました。

## 比較表
見出し:
発達特性のあるお子さんの家庭教師、
「1対1」だけで選んでいませんか？

導入:
見るなら、この3つです。
- お子さんの特性を理解してもらえるか
- 「どこで止まっているか」から学び方を考えてもらえるか
- 家庭での困りごとも相談できるか

列:
比較ポイント / ソウガク / 家庭教師のランナー / 家庭教師のトライ / 家庭教師のサクシード

行:
- 発達特性への位置づけ
- 先生側の支援体制
- つまずき把握→学び方の設計
- 保護者への継続サポート
- 入会前に確認できること

値はスプレッドシート `王道LP_最終稿_v3` の内容をそのまま使用。
比較表は `mt-scroll` + `mt-table` を使い、スマホでは横スクロール可。
ソウガク列は背景や太字で軽く強調してよいが、記号評価は付けない。

比較後は `mt-conclusion` で、
「各社に良さがある」→「今回の3基準ではソウガクの仕組みが一続きで確認できる」
という結論にする。

2. 「いい先生がいるか」だけでなく、先生を支える仕組みがあるか
3. 授業が終わったあとも、親が相談できるか

本文は `王道LP_最終稿_v3` をそのまま使用。

## ランキング
見出し:
発達特性への学習サポートを重視する家庭教師 おすすめ3選

評価基準:
①発達特性を前提にした支援設計
②つまずき把握と個別の学び方づくり
③保護者との継続的な連携

1位 ソウガク
2位 家庭教師のランナー
3位 家庭教師のサクシード

1位ソウガクだけ `mt-spec` で厚く見せる。
ランナー・サクシードは短い説明にする。
トライは「大手の安心感・教師の選択肢・進路支援重視なら有力」と補足。

ランキング後CTA:
無料体験で「この子に合う学び方」を相談してみる

## 感情ブリッジ＋体験談
見出し:
勉強のことを、家の中だけで抱え続けなくてもいい。

本文:
教材を変えた。
塾を探した。
毎日声をかけた。

「今日は怒らないようにしよう」と思ったのに、また言い合いになってしまった。

子どものことが心配だからこそ、つい言ってしまう。
うまくいかない日が続くと、親のほうも疲れてきます。

そんなとき、親がもっと上手に教えられるようになることだけが答えではありません。
家庭の外に、お子さんの困り方を一緒に見てくれる人を増やす。それも一つの方法です。

ここに `mt-review` で公式体験談:
「私がずっと見なくては」というプレッシャーが軽くなった。
（公式掲載内容の要約。詳細文はスプレッドシート正本を使用）

## オンライン不安
見出し:
「家でも集中できないのに、オンラインで大丈夫？」

本文:
無理に「大丈夫です」とは言いません。
子どもによって、先生との相性も、画面越しの授業が合うかどうかも違うからです。

だから、入会してから悩むのではなく、先に体験で見ておく。
先生と話せるか。途中で嫌にならないか。声かけで戻れそうか。
そこを実際に確かめるのがいちばんです。

`mt-info`:
もし、お子さん本人がまだ家庭教師に乗り気ではないなら、
1回目の無料体験を保護者と担当教師の面談にすることができます。

`mt-review` を2枚:
- 最初は画面の前に座っているのも難しかった。
- 集中が切れそうなときも、先生の声かけで戻れた。

## 無料体験
見出し:
合うかどうかは、入会を決める前に確かめていい。

`mt-timeline`:
1. 無料体験を申し込む
2. 教務担当が今の様子や困りごとをヒアリング
3. 無料体験を受ける（2回まで）
4. お子さん用の個別指導計画を受け取る
5. 合いそうなら入会を検討

寄り添い本文とCTAは `王道LP_最終稿_v3` のまま。

## 料金
見出し:
料金のことも、あとから不安にならないように。

代表料金:
- 小学生 25分×月4回 13,200円 / 50分×月4回 22,000円
- 中学生 35分×月4回 18,480円 / 60分×月4回 26,400円
- 高校生 35分×月4回 21,560円 / 60分×月4回 29,920円
※税込

`mt-points`:
保証金0円 / 月会費0円 / 更新費0円 / 教師交代費0円 / 受験生割増なし / 学年内料金UPなし / 高額教材販売なし / 科目数による料金UPなし

`mt-caution`:
入会金22,000円（税込）は別途。
キャンペーン・割引条件は公式確認。

## FAQ
`mt-faq` を使う。
- 診断がついていなくても受けられる？
- 子どもがまだ家庭教師に乗り気ではない。まず親だけで相談できる？
- 集中力が続かなくても大丈夫？
- 先生が合わなかったら？
- 授業中、親はずっとそばにいる必要がある？
- 体験後にしつこく勧誘されない？
- 教材費などは別にかかる？

回答は `王道LP_最終稿_v3` をそのまま使用。

- ランキングが当サイト独自評価だと明記

- 運営者情報 / privacy / disclosure が残っている

- 既存画像を勝手に差し替えない
- 新規画像が必要なら画像生成せず、まず `mt-imgslot` で指示枠だけ置く
