## 0. 方針

- 本文は `王道LP_最終稿_v3.csv` が正本。画像内の文字は本文からそのまま（足さない・言い換えない）
- LPには画像を直接入れず、置き場所すべてに **画像指示枠（`mt-imgslot`）** を置いた。画像ができたら **本文画像（`mt-img`）** に差し替える
- 広告主バナー（`images/12158-1789468146.8095-4.jpg`、ユーザー提供・改変なし）だけは、ランキング1位の順位見出し直後に `mt-banner` で配置済み
- **人物は描かない**：ソウガクのASPの人物画像の可否が未確認のため（パーツ集「分からなければ人物なしで設計」）
- **体験談（`mt-review`）の近くに人物画像を置かない**：公式体験談の要約なので、人物を添えると体験談の本人に見える

## 1. 既存素材の扱い

`images/01〜08`（CC0写真）を先に割り当てられるか確認した。

| 素材 | 判断 |
|---|---|
| 01 / 02 / 04 / 05 / 06 / 07 / 08 | 人物（子ども・保護者・手）が写っている → 人物画像の可否が確認できるまで使わない |
| 03（黒板と教科書） | 人物なしだが、集団授業・教室の絵で v3 の本文（家庭・オンライン）と合わない |

→ 今回はすべて新規生成（人物なし）。ファイルは削除せず保持。

## 2. 配置（375px で画像のない区間を測定）

基準: スマホ1画面（約800px）に画像・表・CTAのどれか1つ以上／文章だけの区間は最大1.5画面（1,200px）。H2の直下は扉。

| 区間 | 枠なし時 | 対応 |
|---|---|---|
| FV | 画像なし | IMG-01（FVの扉） |
| 比較表 → ランキング早見 | 2,247px | IMG-02（選び方のH2直下）＋IMG-03（選び方3.の直下） |
| ランキング後CTA → 無料体験CTA | 3,309px | IMG-04（オンライン不安のH2直下）＋IMG-05（無料体験のH2直下）。感情ブリッジ＋体験談のセクションは体験談があるため置かない |
| 料金 → 最終CTA | 1,978px | IMG-06（FAQのH2直下）＋IMG-07（最終CTAのH2直下） |

配置後の最大区間は、IMG-04 → IMG-05 の **1,237px**（オンライン不安の本文＋公式体験談2件）。体験談の区間に画像を足さないため、基準をわずかに超えたままにしている。
