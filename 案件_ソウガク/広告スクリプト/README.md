# ソウガク｜Google 広告スクリプト

## 品質スコア書き出し.js

キーワードごとの品質を、毎日「ソウガク PPC広告運用 CPA分析」シートに書き出す。読み取り専用で、広告・入札・予算は変更しない。
書き出す項目は、品質スコア／LPの利便性／広告の関連性／推定クリック率。

- 書き出し先のタブ（毎回上書き。既存のタブには触らない）
  - `品質スコア_KW`：キーワードごとの品質4項目と直近30日の表示回数・クリック・費用、着地先URL
  - `品質スコア_AG`：広告グループごとの「LPの利便性」の内訳（表示回数で重み付け）と品質スコアの加重平均
- 対象：キャンペーン「①王道」「②その他ジャンル」「③競合」「④テール」（`CONFIG.CAMPAIGN_NAMES` で変更）

### 設置手順（初回だけ）
1. Google 広告でソウガクのアカウントを開き、ツール → 一括操作 → スクリプト → ＋（新しいスクリプト）を選ぶ
2. このファイルの中身を全部貼り付け、名前を「品質スコア書き出し」にする
3. 「承認」を押し、広告アカウントとスプレッドシートへのアクセスを許可する
4. 「プレビュー」でエラーがないことを確認してから「実行」する
5. 頻度を「毎日」（午前6時ごろ）にする。PC の google-ads-operations の更新とは別に動く

### 注意
- 品質スコアは表示回数がたまるまで「—」（未評価）になる。配信開始直後は未評価が多い。
- 品質の値は書き出した時点のもの。実績（表示回数など）は直近30日。
